# Revision reports

- `Revision_Report.docx`: review comments from every Deep Review round and the change made for each. Revision 0 (changes before the first upload) is already filled in. Fill in Rounds 1–3 as you go.
- Save the raw Deep Review output of each round next to it, for example `DeepReview_Round1.pdf`, `DeepReview_Round2.pdf`, `DeepReview_Round3.pdf`.
- Keep the PDF you uploaded in each round as `CARE_paper_R0.pdf`, `CARE_paper_R1.pdf`, and so on.

Everything in this folder is included in `dist/CARE_Final_Submission.zip` by `python scripts/build_submission.py pdf standalone package`.
