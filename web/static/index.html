1. The Reactive Bottleneck

Why Normal 5G Handovers Drop

A standard 5G network waits until the car actually crosses the cell boundary before requesting radio resources at Tower C0. If Tower C0 is congested with background broadband traffic, only partial capacity (e.g. 3/7 RBs) is available — Handover fails and the uRLLC link disconnects.

2. PPO Reinforcement Learning

Anticipating the Crossing

The ProRAN agent monitors vehicle mobility telemetry and distance proxies. Approximately 1.5 seconds before arrival, PPO chooses to issue an advance reservation contract for 8 RBs at target Tower C0, protecting critical capacity ahead of time.

3. Zero-Drop Admission

Guaranteed SLA Satisfaction

When the car reaches Tower C0, its 7 RBs are already reserved and instantly allocated. Full throughput is met (7/7 RBs), avoiding radio link failure while releasing unused background blocks immediately back to the pool.

RESEARCH CONTEXT

What this does—and does not—prove.

These are curated six-device teaching traces, not the evaluation set. The saved controller is a linear PPO RL model, not deep learning. Handover target selection is geometric; forecast confidence is heuristic, and signal colors are a distance proxy rather than measured RSRP/SINR. This is a synthetic system-level demonstrator, not a field-ready 5G controller.
