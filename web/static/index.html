RESEARCH CONTEXT

What this does—and does not—prove.

These are curated six-device teaching traces, not the evaluation set. The saved controller is a linear PPO RL model, not deep learning. Handover target selection is geometric; forecast confidence is heuristic, and signal colors are a distance proxy rather than measured RSRP/SINR. This is a synthetic system-level demonstrator, not a field-ready 5G controller.
